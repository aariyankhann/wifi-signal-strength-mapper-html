WiFi Signal Strength Mapper

A web-based WiFi Signal Strength Mapping application developed using HTML, CSS, and JavaScript. The system visualizes wireless signal strength (RSSI) data through interactive heatmaps, contour lines, and access point placement for WiFi coverage analysis.
